# **6\. 체방 시스템**

## **6.1 체방 계수 시스템 개요**

DG의 캐릭터는 동일한 장비를 착용하더라도 직업별 전투 포지션에 따라 생존력이 다르게 적용된다.

이를 위해 캐릭터의 생존 스탯은 단순히 장비 수치만으로 결정하지 않고, 직업별로 별도의 체력 계수와 방어 계수를 적용한다.

이 구조를 통해 같은 등급, 같은 수치의 장비를 착용하더라도 전사는 더 단단하게, 마도사는 더 취약하게, 암살자는 높은 기동성을 가진 대신 낮은 생존력을 가지도록 설계한다.

# **6.2 최종 체력 계산식**

| 최종 체력 \= (레벨 기본 체력 \+ 장비 체력) × 직업 체력 계수 |
| :---- |

| 항목 | 설명 |
| ----- | :---: |
| 레벨 기본 체력 | 캐릭터 레벨에 따라 증가하는 기본 체력 |
| 장비 체력 | 장비에서 제공하는 체력 |
| 직업 체력 계수 | 직업별 생존력 차이를 만들기 위한 보정값 |
| 최종 체력 | 실제 전투에서 사용하는 체력 수치 |

예시

| 레벨 기본 체력 3000장비 체력 1000직업 체력 계수 1.10최종 체력 \= (3000 \+ 1000\) × 1.10최종 체력 \= 4400 |
| :---- |

# **6\.3 최종 방어력 계산식**

| 실제 방어력 \= (레벨 기본 방어력 \+ 장비 방어력) × 직업 방어 계수 |
| :---- |

| 항목 | 설명 |
| ----- | :---: |
| 레벨 기본 방어력 | 캐릭터 레벨에 따라 증가하는 기본 방어력 |
| 장비 방어력 | 장비에서 제공하는 방어력 |
| 직업 방어 계수 | 직업별 방어 효율 차이를 만들기 위한 보정값 |
| 실제 방어력 | 피해감소 공식에 사용되는 최종 방어력 |

예시

| 레벨 기본 방어력 600장비 방어력 2000직업 방어 계수 1.15실제 방어력 \= (600 \+ 2000\) × 1.15실제 방어력 \= 2990 |
| :---- |

# **6.4 피해감소 공식**

방어력에 따른 피해감소는 아래 공식을 사용한다.

| 피해감소율 \= 1 \- 1 / (1 \+ 0.0001535 × 실제 방어력) |
| :---- |

최종적으로 받는 피해는 아래와 같이 계산한다.

| 최종 피해량 \= 들어온 피해량 × (1 \- 피해감소율) |
| :---- |

예시

| 들어온 피해량 \= 1000실제 방어력 \= 2600피해감소율 \= 1 \- 1 / (1 \+ 0.0001535 × 2600\)피해감소율 ≒ 28.53%최종 피해량 \= 1000 × (1 \- 0.2853)최종 피해량 ≒ 715 |
| :---- |

# **6.7 개발 적용 기준**

개발 구현 시 체력과 방어력은 아래 순서로 계산한다.

| 1\. 레벨 기본 체력 계산2\. 장비 체력 합산3\. 직업 체력 계수 적용4\. 레벨 기본 방어력 계산5\. 장비 방어력 합산6\. 직업 방어 계수 적용7\. 피해감소율 계산8\. 최종 피해량 계산 |
| :---- |

최종 공식은 아래와 같다.

| RawHP \= BaseHPByLevel \+ EquipmentHPFinalHP \= RawHP × ClassHPCoefficientRawArmor \= BaseArmorByLevel \+ EquipmentArmorEffectiveArmor \= RawArmor × ClassDefenseCoefficientDamageReduction \= 1 \- 1 / (1 \+ 0.0001535 × EffectiveArmor)FinalDamageTaken \= IncomingDamage × (1 \- DamageReduction)EffectiveHP \= FinalHP / (1 \- DamageReduction) |
| :---- |

## **9.1 전사**

전사는 근접 전투와 그로기 누적에 특화된 직업이다. 

짧은 사거리 대신 높은 체력과 방어력을 가지고 있으며, 보스에게 붙어서 지속적으로 압박하는 역할을 담당한다.

| :---- | :---- |
| 전투 거리 | 근거리 |
| 주 역할 | 근접 딜러 / 그로기 누적 |
| 난이도 | 낮음\~중간 |
| 강점 | 생존력, 안정성, 그로기 누적 |
| 약점 | 원거리 대응 부족, 보스 패턴 숙지 필요 |

| 4 | 발목 베기 | 타겟형 | 4M | 즉시 | 10초 | 0 | 3초 둔화, 그로기 10 |
| Q | 분쇄 파동 | 자기중심 광역 | 4M | 즉시 | 20초 | \-250 | 주변 피해, 그로기 5 |
| E | 파멸의 맹타 | 타겟 돌진 | 8M | 즉시 | 30초 | \-250 | 돌진, 5초간 그로기 \+15%, 그로기 15 |

### **전사 운용 방식**

기본 공격으로 정신력을 회복한 뒤, 절단의 맹타와 분쇄 파동으로 피해를 넣는다. 보스와 거리가 벌어졌을 때 내려찍기와 파멸의 맹타로 재진입한다. 발목 베기는 일반 몬스터 또는 이동형 보스 패턴 대응용으로 사용한다.

## **9.2 궁사**

궁사는 긴 사거리와 높은 기동성을 가진 원거리 딜러이다. 

안전한 거리에서 지속 피해를 넣으며, 출혈과 속도 버프를 활용해 파티 전투를 수행한다.

| 항목 | 내용 |
| :---- | :---- |
| 전투 거리 | 원거리 |
| 주 역할 | 지속 딜러 / 기동 지원 |
| 난이도 | 중간 |
| 강점 | 긴 사거리, 높은 치명타, 안정적 딜링 |
| 약점 | 낮은 방어력, 근접 대응 취약 |

### **궁사 스킬 목록**

| 슬롯 | 스킬 | 타입 | 사거리 | 시전 시간 | 쿨타임 | 정신력 | 핵심 효과 |
| :---- | :---- | :---- | :---- | :---- | :---- | :---- | :---- |
| 1 | 저격 | 타겟형 / 3타 콤보 | 20M | 즉시 | 1초 | \+120 | 기본 공격 |
| 2 | 속사 | 타겟형 | 20M | 즉시 | 0.5초 | \-96 | 대상 주변 4M 피해 |
| 3 | 송곳 화살 | 타겟형 | 20M | 즉시 | 5초 | \+100(치명타시) | 치명타 시 출혈,  그로기 5 |
| 4 | 광풍 화살 | 타겟형 / 차지스킬/버프 | 20M | 0.5/1/1.5초 | 20초 | \-200 | 5/7/10초간 아군 속도 \+8%, 그로기 10 |
| Q | 조준 화살 | 타겟형/ 차지스킬 | 20M | 0.5/1/1.5초 | 20초 | \-200 | 그로기 대상 추가 피해 \+20%, 그로기 10 |
| E | 표적 화살 | 위치지정 이동기 | 20M | 즉시 | 10초 | \-50 | 화살 위치로 순간이동 |

### **궁사 운용 방식**

저격과 속사를 통해 원거리에서 정신력 순환과 지속 피해를 담당한다. 송곳 화살은 출혈 유도, 조준 화살은 그로기 타이밍 폭딜용이다. 표적 화살은 위험 장판 회피 또는 포지션 재배치에 사용한다.

## **9.3 마도사**

마도사는 강력한 마법 피해와 광역 제어를 가진 원거리 캐스터이다. 

체력과 방어력은 낮지만, 화상/둔화/버프/차지 폭딜을 통해 보스전과 다수전에서 높은 영향력을 가진다.

| 항목 | 내용 |
| :---- | :---- |
| 전투 거리 | 원거리 |
| 주 역할 | 마법 딜러 / 버퍼 / 광역 제어 |
| 난이도 | 중간\~높음 |
| 강점 | 광역 피해, 화상, 공격력 버프, 차지 폭딜 |
| 약점 | 낮은 생존력, 정신력 관리 필요 |

### **마도사 스킬 목록**

| 슬롯 | 스킬 | 타입 | 사거리 | 시전 시간 | 쿨타임 | 정신력 | 핵심 효과 |
| :---- | :---- | :---- | :---- | :---- | :---- | :---- | :---- |
| 1 | 불꽃 화살 | 타겟형 / 3타 콤보 | 20M | 즉시 | 1초 | \+100 | 기본 공격 |
| 2 | 얼음 사슬 | 타겟형 / 2타 콤보 | 20M | 즉시 | 0.5초 | \-120 | 대상 주변 4M 피해, 그로기 2 |
| 3 | 불꽃 작살 | 타겟형 | 20M | 즉시 | 5초 | \-250 | 치명타 시 화상, 그로기 5 |
| 4 | 집중의 기원 | 논타겟 버프 | \- | 즉시	 | 60초 | \-100 | 20초간 아군 공격력 \+10% |
| Q | 지옥의 화염 | 타겟형 / 차지 | 20M | 0.5/1/1.5초 | 45초 | \-200 | 4M 범위 피해, 차지별 그로기 20/25/35 |
| E | 혹한의 바람 | 타겟 위치 AoE | 20M | 즉시 | 20초 | \-150 | 2초간 4M AoE, 둔화, 그로기 10 |

### **마도사 운용 방식**

불꽃 화살로 정신력을 회복하고, 얼음 사슬과 불꽃 작살로 지속 피해를 넣는다. 집중의 기원은 파티 딜 타이밍에 맞춰 사용하며, 지옥의 화염은 보스가 고정되거나 그로기 상태일 때 사용하는 핵심 폭딜 스킬이다.

## **9.4 암살자**

암살자는 높은 기동성과 후방 공격 보너스를 가진 근접 폭딜러이다. 

보스의 후방을 잡고 빠르게 피해를 넣은 뒤, 이동 스킬로 빠져나오는 플레이를 지향한다.

| 항목 | 내용 |
| :---- | :---- |
| 전투 거리 | 근거리 / 순간 접근 |
| 주 역할 | 기동 딜러 / 백어택 딜러 |
| 난이도 | 높음 |
| 강점 | 높은 치명타, 후방 추가 피해, 이동기 |
| 약점 | 낮은 방어력, 조작 난이도 높음 |

### 

### **암살자 스킬 목록**

| 슬롯 | 스킬 | 타입 | 사거리 | 시전 시간 | 쿨타임 | 정신력 | 핵심 효과 |
| :---- | :---- | :---- | :---- | :---- | :---- | :---- | :---- |
| 1 | 빠른 베기 | 논타겟 / 3타 콤보 | 4M | 즉시 | 1초 | \+100 | 기본 공격 |
| 2 | 기습 | 논타겟 | 4M | 즉시 | 1초 | \-100 | 후방 공격 시 피해 \+50%, 그로기 7 |
| 3 | 암습 | 타겟형 | 20M | 즉시 | 20초 | \-150 | 공격 후 반대 방향 이동, 그로기 10 |
| 4 | 섬광 베기 | 타겟형 | 4M | 즉시 | 10초 | 0 | 공격 후 반대 방향 이동, 그로기 7 |
| Q | 심장 찌르기 | 논타겟 | 4M | 즉시 | 5초 | \+100(치명타시)  | 치명타 시 방어도 감소, 그로기 5 |
| E | 침투 | 전방시전형 | 10M | 즉시 | 20초 | 0 | 10M 이동 공격, 보스 관통 가능, 그로기 10 |

### **암살자 운용 방식**

빠른 베기로 정신력을 회복하고, 기습과 심장 찌르기로 후방 폭딜을 노린다. 암습과 섬광 베기는 공격 후 위치를 바꾸는 회피형 공격 스킬이다. 침투는 보스를 관통하며 위치를 재조정하는 핵심 생존 겸 딜링 스킬이다.

# **11\. 그로기 시스템 연동**

보스는 별도의 그로기 게이지를 가진다. 플레이어 스킬 중 일부는 체력 피해와 별도로 그로기 피해를 준다.

| 항목 | 내용 |
| :---- | :---- |
| 그로기 게이지 | 보스별 보유 |

| 그로기 발생 | 게이지가 최대치에 도달하면 발생 |
